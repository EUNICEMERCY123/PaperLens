## Executive Summary

Traditional document QA tools treat PDFs as flat streams of plain text. When documents contain **complex tables, plotted line/bar charts, multi-column layouts, or degraded scanned pages**, text-only pipelines produce either complete blindness or hallucinated answers.

**PaperLens** solves HackNex Challenge **HNX26PSI01** by transforming document understanding into an **evidence-first multimodal workspace** founded on a strict operational rule:

> **NO UNSOURCED ANSWERS.**
> Every factual statement generated by PaperLens is mathematically verified, linked to its exact source document and page number, and immediately inspectable through high-resolution visual page proofs.

---

## 1. Core Product Mental Model

$$\text{Upload} \longrightarrow \text{Understand} \longrightarrow \text{Ask} \longrightarrow \text{Prove}$$

1. **Upload**: Ingest single or multiple PDFs with mixed modalities (normal text, financial tables, plotted graphs, scanned memos).
2. **Understand**: Page-aware extraction parses tabular rows, detects graphical drawings, renders 150 DPI page visual representations, and activates multimodal OCR for image-only pages.
3. **Ask**: Natural-language questions query across all documents with intelligent scope selection and recommended prompt chips.
4. **Prove**: Answers are returned with **confidence ratings**, **evidence coverage pills**, **programmatically verified math**, and **interactive visual page proofs** with zoom and navigation controls.

## 4. Key Differentiators & Engineering Highlights

### 1. Deterministic Numerical Engine (Zero Math Hallucination)
LLMs are notoriously prone to arithmetic mistakes when calculating percentage changes, differences, and compound growth. PaperLens extracts source values through visual inspection, passes the expression to a programmatic Python engine (`calculation_service.py`), verifies the exact numerical change, and displays the calculation steps directly to the user with a `✓ Verified by Python Arithmetic Engine` badge.

### 2. High-Resolution Visual Inspection of Charts
Rather than hallucinating chart numbers from surrounding paragraphs, PaperLens renders PDF pages at 150 DPI, detects graphics/drawings via PyMuPDF bounding heuristics, and sends the visual image of the chart to Gemini Multimodal Vision.

### 3. Automatic Scanned Document Fallback with Caching
Degraded or scanned documents (such as legacy audit memos or printed contracts) produce 0 extractable text characters via standard PDF parsers. PaperLens detects low text density, routes the page to Gemini Vision OCR, and saves the transcript to `.ocr.txt` on disk so subsequent queries run with zero latency.

### 4. Interactive Page-Proof Modal with High-Res Zoom
Every citation card includes an `Inspect Page Proof ↗` button. Clicking it opens a modal overlay featuring:
- Rendered 150 DPI page image from `/api/documents/{doc_id}/pages/{page}/image`.
- Zoom controls (50% to 250% + Reset).
- Page navigation (Previous Page / Next Page).
- Verbatim excerpt and extraction confidence score.

## 6. Local Setup & Execution Guide

### Prerequisites
- **Python:** 3.10+ (Tested on Python 3.14 / 3.13)
- **Node.js:** 18+ and npm
- **Google Gemini API Key:** [Get an API key](https://aistudio.google.com/)

### 1. Environment Setup

Copy `.env.example` in `backend/` to `backend/.env` and supply your Gemini API key:
```bash
GEMINI_API_KEY="your-gemini-api-key-here"
```

### 2. Backend Execution

```bash
cd backend

# Install dependencies (if not already installed)
pip install -r requirements.txt

# Start FastAPI server
uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```
The backend API is now live at: `http://127.0.0.1:8000`  
Interactive Swagger docs: `http://127.0.0.1:8000/docs`

### 3. Frontend Execution

```bash
cd frontend

# Install packages
npm install

# Run Vite dev server
npm run dev
```
The frontend application is now live at: `http://127.0.0.1:5173`

## 9. Limitations & Future Work

1. **Massive Datasets (>100 PDFs):** Current in-memory registry is optimized for hackathon speed and local execution. For enterprise scaling, swap the document registry with a pgvector or ChromaDB vector store.
2. **Dense Multipage Tables:** Single-page table extraction uses PyMuPDF grids. Continuous multi-page tables spanning 5+ pages can be joined via column schema continuity.
3. **Interactive Bounding Box Draw:** The viewer currently displays highlighted excerpts and page renders. Future versions can overlay interactive SVG bounding boxes directly on top of the rendered image.
